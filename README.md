# Para a Sheila ♡

Landing page estática (HTML + CSS + JS). Sem build, sem dependências.

## Publicar no GitHub Pages
1. Cria um repositório novo no GitHub (ex.: `para-sheila`).
2. Envia estes ficheiros para a raiz do repositório (arrasta-os em *Add file → Upload files*).
3. *Settings → Pages → Source: Deploy from a branch → main / (root) → Save*.
4. Em ~1 minuto o site fica em `https://SEU-USER.github.io/para-sheila/`.

## Notas
- A música é o vídeo oficial do YouTube; só toca em `https://` (GitHub Pages), não ao abrir o ficheiro direto no computador.
- As fotos estão em `assets/`. Para trocar, substitui os ficheiros mantendo os nomes.
